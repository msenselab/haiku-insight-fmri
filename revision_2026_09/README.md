## Important distinctions

- CA = context–action; JX = juxtaposition; OI = one-image. Button presses are reported understanding, not objective comprehension or liking.
- The historical 0.5-s first-response Search/Pre GLM, matched raw-clock 0.5-s/1-s response-window sensitivity, 0.5-s Post model, RT-modulated onset-to-first-response model, first-three-retained-press multiple-response GLM, and condition-adjusted first/final order model have **different estimands and, in places, different eligible target sets**. The historical `FirstResponseJointW05` uses 779 CSV-timed target responses; the raw-clock width-matched W05/W10 pair uses 764 targets and 15 fast-response nuisance events. Do not claim that `DurationSensitivityW10` differs from historical `FirstResponseJointW05` **only** by event duration, or substitute their maps.
- Whole-brain activation uses cluster-FWE **within each contrast map** as the manuscript inference; no cross-map correction is invoked here. Group coefficient-vs-zero gPPI tests are not direct condition comparisons; their separately reported within-target×interval Holm3 and broader-family columns concern gPPI, **not whole-brain map selection**. gPPI is not causal or directed evidence.
- `data/ppi/N19_first_final_group_coefficients.csv` retains its original **broad Holm12** column for provenance; the manuscript's retrospective **within-target×interval Holm3** values are in `data/ppi/N19_retrospective_Holm3_ledger.csv`. The direct pooled First–Final angular test is N18, not an N19 coefficient-level test. Published Figure 7 uses a historical angular target, not a post-response-coordinate sensitivity.
