# Haiku insight fMRI — revised-manuscript evidence

This tree is aligned to the revised manuscript's Google Doc tab `t.0` (September 2026), not to the older May manuscript. See [`revision_2026_09/README.md`](revision_2026_09/README.md) for the exact seven embedded figures, model-specific scripts, and selected aggregate result tables. The separate [`unthresholded_tmaps/`](unthresholded_tmaps/) folder contains **13 signed, unthresholded N=19 group t-maps**, named by model and contrast. The W10 phase-interaction t-map, retrospective one-sided group-only readback code, and aggregate results are now included separately from the W10 Pre CA>JX simple effect. The original two-sided interaction test remained null (*p*FWE=.08844); the positive one-sided readback (*p*FWE=.0318) was chosen after that result and is exploratory, not a prespecified duration-only confirmation.

## Current analysis scope

- Figures 1–2: model timing schematic and aggregate response counts.
- Figure 3: first-response RT by CA/JX/OI. The embedded image is `revision_2026_09/figures/figure3.png`. The retained older `figures/figure1_behavioral_rt.png` has identical rendered pixels. Its existing public input/code are `code/01_behavioral_stats.py`, `code/01_plot_behavioral_rt_figure.py`, `data/behavioral/behavioral_rt.csv`, `data/behavioral/figure1_rt_subject_values.csv`, and `data/behavioral/figure1_rt_summary.csv`; higher-resolution source assets remain in `figures/source_panels/fig_behavioral_rt_first_insight_conditions*`. This is **existing public participant-level behavioral data**, not newly released participant-level coefficients. Run the plotting script without an output override to regenerate into a fresh temporary directory; `HAIKU_FIGURE3_OUTPUT_DIR` can select a destination **outside** this checkout, preserving the tracked original image/PDF/CSV.
- Figures 4–6: revised Search/Pre-response, multiple-response, and response-order activation. Whole-brain inferences use permutation **cluster FWE within each contrast map** (not across-map Holm). Figure 6C's descriptive participant traces are captured in the exact Doc image; the *displayed* 19/19/15 aggregate source summary is in `revision_2026_09/data/response_order/`. The valid but undisplayed 19/18/15 variant is retained only in the internal project. Figure 6C is post-selection description, not a second inferential test.
- Figure 7: exploratory condition-specific gPPI. Its coefficient tests and targeted correction are distinct from whole-brain map inference. The release includes aggregate gPPI tables but no new participant-level gPPI vectors.

## What is not in the current evidence tier

The only root `data/`, `code/`, and `figures/` entries retained are the existing public **Figure-3 behavioral RT** inputs, scripts, summaries, and matching images. Unmatched May processed outputs (legacy Z maps, GCA/FC, PCC×RT PPI, ROI and participant-level tables), scripts, figures, reports, and May-only provenance notes have been removed from the current tree; previously public versions remain recoverable in Git history, **not erased from the public repository's history**. No raw MRI or single-subject fMRIPrep derivatives are added. The selected model scripts need protected inputs, so this public tier cannot rerun the full fMRI pipeline or regenerate every participant-dot panel. The 13-map set is findings-focused, not all tested null contrasts and not a NeuroVault deposit.

## Verify the selected current tier

From repository root with Python, NumPy and nibabel installed:

```bash
python revision_2026_09/code/verify_release.py
```

This validates figure and t-map hashes, map dimensions/sign/finiteness, public aggregate-table integrity, script syntax, and selected manuscript result landmarks. It is **not** a raw-to-results reproduction or a data-sharing/license certification.

**Inference and manuscript scope:** Main whole-brain findings in this package use **within-map cluster FWE**; no cross-map Holm gate is imposed on them. The live supplementary S1 consists of example haiku; no poem text is redistributed here. `revision_2026_09/data/supplement/` now contains only a [scope note](revision_2026_09/data/supplement/README.md) and the N=19 Early–Middle–Pre-response **single-GLM** S2 map ledger (21 tested maps) and cluster table (41 within-map-FWE clusters). The map ledger is a companion analysis record, not a table printed in live S2; its full three-phase model source/inputs are not provided by the public package. The three previously mislabelled `S1_*` power-simulation CSVs were removed from the current tree, not rewritten out of Git history. The S2 ledger retains historical family-A/B map-minimum Holm columns for provenance, but its reported clusters use within-map FWE. `DurationSensitivityW10` is **not** the historical `FirstResponseJointW05` with only the window changed: the former's matched raw-clock width comparison has 764 target responses and 15 fast-response nuisance events; the latter uses 779 CSV-timed target responses and different nuisance/design handling. The W10 interaction's saved two-sided analysis was null (*p*FWE=.08844), whereas a **retrospectively chosen positive one-sided** test on the same effects yielded a lingual cluster (*k*=24; *p*FWE=.0318, second seed .0314). This is an exploratory result, not independent validation of the primary W05 interaction. The selected package lacks protected input data needed to rerun all analyses, while the manuscript's data/code-availability sentence is broader; it is not a complete raw-to-results reproduction.
