# Group unthresholded contrast t-maps — revised haiku manuscript

This folder collects **12 three-dimensional N=19 group t-statistic maps** for the whole-brain activation contrasts behind the revised manuscript's principal findings (live Google Doc manuscript tab `t.0`, read 2026-09-26). The NIfTI files were **copied byte-for-byte** from their model-specific analysis outputs, not thresholded, masked to significant clusters, converted from a log-p/z image, or re-estimated. Each filename starts with the **model** and includes the **contrast**, followed by `stat-t_desc-unthresholded`. `manifest.csv` and `manifest.json` give each source path, direction, manuscript location, file size and SHA-256 digest. All source/copy hashes were checked after copying. Whole-brain inference here is **within-map cluster FWE**; cross-map Holm is not used to select or describe these maps.

## Included models

- `FirstResponseJointW05` — first-response, jointly modeled Search and the final **0.5 s before the first press**: Pre CA > JX; Search JX > OI; and `[Pre(CA−JX)] − [Search(CA−JX)]` (Figure 4A). These are distinct maps, not an inference about a difference obtained by comparing two thresholded maps.
- `DurationSensitivityW10` — response-window sensitivity, final **1 s before the first press**, with Search ending when the wider window begins: **Pre CA > JX only** (Results, “Pre-response 1-s model”). Figure 1B depicts the *model*, not an activation map. The Pre map and its distinct `revision_2026_09/code/one_second_pre/run_duration_sensitivity.py` source use the nonoverlapping `section3_duration_sensitivity_20260908` analysis. The later group-only **1-s phase-interaction** suite's two-sided CA–JX interaction did **not** survive within-map cluster FWE (minimum *p*FWE=.08844); its runner and interaction map/table are excluded from this release. The older `extended_1s_models/pre1p0` output overlaps Search and Pre and is not substituted here.
- `PostResponseW05` — first **0.5 s after the first press**, CA > JX (Results, “Post-response 0.5s model”; Figure 1C is its schematic).
- `OnsetToFirstResponseRT` — full poem-onset-to-first-press interval with condition-specific centered RT modulators, CA > JX (Results, “Onset-to-First-Response model”; Figure 1D is its schematic). The packaged `manual_t_from_n19_stack` source agrees with the original group t-map to <5×10⁻¹⁵ on its finite voxels and encodes 91 original undefined constant voxels as zero rather than NaN, making a finite map; this is **not** a thresholded derivative.
- `AllResponseJointW05` — multiple-response Search–Pre model, with up to three **retained CSV presses per presentation**, N=19 (Figure 5): Pre CA > JX; Pre OI > JX; Search JX > OI; and `[Pre(JX−OI)] − [Search(JX−OI)]`. The negative tail of the last, original signed map shows the manuscript's **OI−JX** larger in Pre than Search; **do not mistake the positive-tail filename for the effect direction**. No sign was flipped or new t-statistic derived for this package.
- `ResponseOrderFirstFinalW05` — condition-adjusted, CSV-limited first-versus-final response-order model (Figure 6): Search final > first and Search first > final. These are two distinct directional group contrasts. The Pre-response order contrasts were not included because they had no corrected clusters. This analysis is not a causal order effect or an independent replication.

**Statistic-header caveat.** The archived `PostResponseW05` image was written by Nilearn `non_parametric_inference` as its `outputs['t']` image. Its copied NIfTI header retains Nilearn's generic `effect_size of contrast ...` description, also found on that run's `size` and `logp` outputs. This header is misleading: the source runner compared its voxel array to the independently computed parametric `output_type='stat'` t image with `np.allclose(rtol=1e-5, atol=1e-5)` before accepting the map. The public map is the byte-identical original t array, not a header-rewritten derivative. See `revision_2026_09/code/post_response/rebuild_group_inference.py` for that assertion; do not infer statistic type from `descrip` alone.

**Inference scope.** The primary FirstResponseJointW05 CA−JX interaction reaches within-map cluster FWE p=.03592 and is retained. This is a voxel/cluster-wise within-contrast-map inference, not a cross-map adjustment. The separate null two-sided 1-s phase interaction's code/map/table are not in this selected release.

Scope: whole-brain **activation** findings with reported within-map FWE clusters, plus the manuscript's named response-window/full-interval sensitivity findings (excluding the 1-s phase interaction). Exploratory ROI–behavior correlations, targeted gPPI/FC coupling, the supplementary three-phase model, null contrasts and N18/N20 sensitivity analyses are **not** t-maps in this selected set. This is a findings-focused package, **not** a NeuroVault upload or a claim that every tested contrast has been released. The sign-flip within-map cluster-FWE results are described in the manuscript/source ledgers; these unthresholded NIfTI arrays alone do **not** mark statistical significance.
